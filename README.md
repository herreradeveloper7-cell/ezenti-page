# ByEzenti Shopify Store 🛍️

Shopify storefront developed and customized for **ByEzenti**, a fashion brand focused on delivering a modern and responsive e-commerce experience.

The project includes theme customization, reusable Liquid sections, responsive storefront components and e-commerce integrations.

---

## Overview

This repository contains the customized Shopify theme used for the ByEzenti online store.

The project focuses on:

- Custom Shopify theme development
- Responsive storefront implementation
- Product and collection presentation
- Reusable Liquid sections and snippets
- E-commerce experience improvements
- Theme maintenance and ongoing customization

---

## Key Features

- 🛍️ Product and collection pages
- 🧩 Custom Liquid sections
- 🎯 Featured product and collection components
- ⏳ Countdown and promotional banners
- 📢 Announcement bar customization
- 🧭 Custom header and navigation
- 🧾 Footer customization
- 🌍 Localization support
- 📱 Responsive storefront behavior
- ⚙️ Shopify theme configuration
- 🧱 Reusable snippets and modular theme structure
